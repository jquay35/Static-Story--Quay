# React Static Story Page

This is a simple React app that displays a static page for the story "The Tortoise and the Hare" using 3 components: Header, Content, and Footer.

## How to run
1. Open a terminal in this folder (story-app)
2. Install dependencies:
   npm install
3. Start the dev server:
   npm start
4. Open:
   http://localhost:3000
